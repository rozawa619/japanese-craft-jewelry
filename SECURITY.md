# Security policy

This is a static editorial site. Do not publish credentials, personal order data, or exploitable vulnerability details in public Issues.

For a suspected security vulnerability, use [Report a vulnerability privately](https://github.com/rozawa619/japanese-craft-jewelry/security/advisories/new). GitHub sign-in is required. Private vulnerability reporting was enabled on 2026-11-16. This channel does not promise a response time or a bounty.

Public editorial corrections may use the repository Issues. Architecture, safeguards and hosting limitations are documented in [docs/security.md](docs/security.md).

未修正の脆弱性や秘密情報は公開Issuesへ書かず、上記の非公開報告を使ってください。一般の掲載訂正とセキュリティ報告は窓口を分けます。
