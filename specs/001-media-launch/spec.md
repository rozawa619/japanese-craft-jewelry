# 001 初期メディア仕様

2026-11-16 / SDD / 状態：初期版実装・検証完了、公開結果はdeployment-results参照

目的：海外読者が日本の工芸アクセサリーを比較し、確認できない点も理解して公式販売店へ進める英語メディア。販売・決済・発送・会員登録は対象外。

| ID | 要件と受入条件 |
|---|---|
| FR-001 | 一次情報を実読した商品を掲載。確認日・出典・不明値・製造地と販売地を区別する。6〜10点を目標とし確証を優先。 |
| FR-002 | 商品・産地・技法・素材・工房・販売店・広告設定・記事・部品を安定IDで分離。存在しない参照は検証で失敗する。 |
| FR-003 | 商品単位とプログラム単位の承認、HTTPS広告URL、リンク確認日が揃う場合だけ広告URLへ切替。その他は通常URL、通常URLなしはCTAなし。 |
| FR-004 | 共通部品でsponsoredと広告開示を一致させる。最初の広告リンクの前で開示。プログラム指定文言も設定から反映。 |
| FR-005 | 商品一覧の種別・産地・素材・技法の組合せ、解除、0件、未知値除外が機能する。 |
| FR-006 | トップ、商品一覧/個別、神奈川、技法、工房、ガイド4本、方針5種、404を実装。空の都道府県は生成しない。 |
| FR-007 | 写真は許諾済みだけ。初期版は自作抽象図柄を実物ではないと明記。架空のレビュー/重量/アレルギー保証/著者実績なし。 |
| FR-008 | スマホ/PC、キーボード、フォーカス、見出し、コントラスト、長い見出しを検証。 |
| FR-009 | 公開URLがないプレビューはnoindex、canonical/OG URLやサイトマップに架空URLを出さない。公開切替チェックは不足を失敗扱い。 |
| FR-010 | About/Contact/Privacyは実装実態に一致。未提供の個人情報を作らない。実際の連絡先がない場合は申請ブロッカーにする。 |
| FR-011 | 比較表・選定理由・注意点・出典を同じ正規化データで表示。実物比較をしたとは書かない。 |
| FR-012 | 他メディアから一般機能のみ学び、文章/画像/特徴的な見た目を複製しない。調査と設計仮説を分ける。 |
| FR-013 | 全ソース、ロック、起動、ビルド、テスト、公開設定、引継ぎを残す。 |

仮定：名称ITO（商標・ドメイン取得未実施）、英語/en/、静的サイト、初期解析なし、課金なし。公開コンテンツは販売店への通常リンク。ブランドは全国展開できる名前。公開/審査/承認を別判定する。
