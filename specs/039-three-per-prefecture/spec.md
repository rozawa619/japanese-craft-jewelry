# 039 掲載が2点の県の工芸アクセサリーを追加

| 要件 | 実装 | 確認方法 |
| --- | --- | --- |
| 掲載が2点の県を優先し、各県3点以上を目安にする | 135商品が掲載された開始時の台帳から対象を抽出。日英の商品ページ、県ページ、技法・素材に既存のIDで紐づける | ソース台帳と全47都道府県の日英ページで公開件数を数える |
| ネックレスやリングも選べる | 産地・作り手・技法に根拠があり、現行の個別販売ページを確認した品から選ぶ。耳飾りなどの製品も、地域の代表的な技法を示す場合は採用する | 注文URL、商品名、注文仕様、国内表示価格、在庫表示または受注条件を商品ごとに確認する |
| 通販注文と現地の取扱いを確認する | 購入根拠に仕様、価格、確認日を登録する。訪問先は公開店舗の根拠を記録し、同じ色や号数の店頭在庫が確認できない場合は個別に案内する | [一次情報と調査結果](../../docs/research/three-per-prefecture-2026-11-24.md)と折りたたみの出典欄を照合する |
| 日英で形を見て選べる | 着用と単体のAIイメージ、着こなし、比較、購入前の3問を追加。公式商品ページへ進めるようにする | 日英のスマートフォン幅で画像、リンク、店舗案内を確認する |
| 配信状態を引き継ぐ | アプリのGitコミットと公開QAの記録を残す。次回編集の正本は[編集ガイド](../../docs/editing-guide.md)に従う | [検証記録](validation.md)と[公開記録](../../docs/deployment-results.json)を確認する |

在庫と価格の基準日は日本時間で記録する。購入フォーム、選択肢、販売元の在庫表示を調べ、注文や決済は行わない。
