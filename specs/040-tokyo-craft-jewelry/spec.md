# 040 東京の工芸アクセサリーを拡充

| 要件 | 実装 | 確認方法 |
| --- | --- | --- |
| 東京の掲載を10点程度に増やす | 確認基準を満たした江戸切子の指輪、東京銀器のバングル、東京七宝・江戸刺繍・江戸漆器のピアスを各1点登録。日英の東京ページで比較できる | 日英の東京ページに既存5点と新規5点の詳細リンクがあることを確認 |
| 東京の工芸との関係を示す | 商品ページ、作り手、都の工芸資料を照合。工芸品目や工房の根拠を示し、個別商品の認証は確認した記録がある場合に限る | [一次資料](../../docs/research/tokyo-craft-jewelry-2026-11-24.md)と日英の出典欄を照合 |
| 型・色ごとの購入案内 | 国内の税込価格、注文時の仕様、確認日、受注生産の目安を記録。店頭案内を確認できた松江の工場は予約制と明記 | 公式通販の注文情報を読み、日英の主購入リンクと購入仕様を照合 |
| 実物と画像を区別 | メーカー名・商品名と確認できた事実を使った独自の紹介文を掲載。文章から作った新しい着用・単体イメージにAI表示を付け、販売元の実物情報に案内する | 日英の商品ページでAI表示、代替テキスト、購入リンクを確認。既存画像はSHA-256で照合 |
| 公開と引継ぎ | 既存のGitHub Pagesで配信。東京の一次資料、アプリの配信元と実測を記録 | [検証記録](validation.md)と[公開記録](../../docs/deployment-results.json)を参照 |
