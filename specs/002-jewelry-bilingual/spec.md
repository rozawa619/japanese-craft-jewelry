# 002 ジュエリー特化と日英切替
2026-11-16。ユーザー追加依頼：ジュエリーに特化し、右上のボタン一つで日本語と英語を切り替える。

| ID | 受入条件 |
|---|---|
| BI-001 | ピアス・イヤリング・ネックレスを掲載。かんざしは公開対象から外す。事実データと出典は削除せず下書きへ。公開8商品。 |
| BI-002 | /en/と/ja/に同じページ構成と対応商品・記事本文を持つ。ナビだけの翻訳にしない。 |
| BI-003 | PC/スマホのヘッダー右上に言語切替を一つ表示。英語では日本語、日本語ではEnglish。現在のページ・絞込クエリ・ハッシュを維持して相互移動する。 |
| BI-004 | 商品の数値・ID・出典・広告状態は一元管理。日本語は表示テキストと独自本文を分離して管理し、仕様の再入力を避ける。 |
| BI-005 | 広告の二重承認ゲート、通常リンク、開示、未確認値、画像権利方針を両言語で維持。 |
| BI-006 | html lang、見出し、メタ情報、言語リンク、サイトマップを言語に一致。プレビューのnoindexは継続。 |
| BI-007 | 日英の主要ページ、右上切替、スマホ320/390、フィルタ、内部リンク、ビルドを実検証し、同じGitHub/Pagesへ反映。 |
既存の英語slugは保持。初期入口/は/en/。言語の自動判定・外部翻訳サービス・Cookie/localStorageは使わない。国内読者向け日本語でも販売サイトとは誤認させない。名称ITOは継続。
