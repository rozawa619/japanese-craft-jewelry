# 019 地図で選ぶ・店舗地図の継続表示・残タスクと法務

2026-11-17。開始repo HEAD886fc2ea、公開0.16 app86d6c6e6。今回のユーザー依頼を旧AGENTSのMaps都度表示/保存なし方針より優先する。商品事実・価格・画像bytes・公式URLは維持し、アプリ0.17.0として実装する。

- R1 現在の残タスクを棚卸しし、実施可能な修正/記録漏れを完了する。契約・課金・本人情報・権利許諾・所有権/アカウント操作が必要なものを勝手に完了化しない。
- R2 法務を政府・規制機関・サービス公式一次情報で再確認。取得失敗と適用の推論を記録し、全法域/全意匠の適法・AdSense合格を保証しない。
- R3 TOP10とDISCOVERの間へローカルの日本地図。掲載県は代表単体画像/商品数/種類と連動し、県の商品へ到達できる。未掲載県の空ページは作らず、TOP10の根拠/順を維持する。
- R4 DISCOVERは編集上の3県だけ。全掲載県は地図・行き先select・地方別リストから選べる。hoverだけに依存せず、touch/keyboard/noJS/JAEN/320pxを扱う。
- R5 店舗Googleマップを広く常設し、明示的に選択した人には30日間、自動表示。未選択/オフ/期限切れ/旧版/不正設定では接続0。全店舗/日英共通の最小設定だけをlocalStorageへ保存し、店舗とPrivacyから全撤回、複数タブ同期、保存不可fallbackを備える。
- R6 Googleのロゴ/帰属/操作UIを隠さず確認済みShare URLを維持。無条件に第三者へ接続してよいと解釈せず、日英Privacyを実際の通信/保存/撤回に合わせる。広告同意・認定CMPと地図設定を混同しない。
- R7 型/単体/build/データ保持/広告切替/SEO/出典/PCスマホと新地図/同意・ライブMapsを検証し、Git/Actions/公開URLまで確認。引継ぎと全source ZIPを更新する。
