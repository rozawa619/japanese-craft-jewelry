# 013 全商品のAI着用イメージと海外向け検索の改善

2026-11-17 / Version0.13.0 / 作業中

依頼：画像のない商品を基本すべて補い、日本人だけでなく米国/英国の女性、かわいい系/美人系を織り交ぜる。海外で検索から見つけやすいか点検し、足りない検索の土台と内容を改善する。

- R1 現公開50品のうち未登録23品に1品ごとの新しいAIスタイリング画像を追加し、全50品を登録画像でカバーする。旧25画像/27品は非破壊で保持。今回は012の『新画像なし』より最新の画像追加依頼を優先する。
- R2 新23画像の架空成人モデルは27〜33歳を目安に、日本/米国/英国の設定とcute/elegantを混ぜる。国籍を外見から断定したり、人種を国籍へ固定したりしない。ほくろ/シミなしという既存希望を継承し、成人らしさを保つ。ブランドロゴ/文字/実在人物の似顔/写真転載なし。
- R3 商品の公式情報と参照可能な実物写真を確認し、素材・色・形を踏まえた独立のAI装いイメージを作る。実物の正確な再現/試着/使用や購入した証拠とはしない。短いAIイメージ/AI image caption、説明方針と近接する公式実物リンクを維持する。
- R4 耳飾り/胸元/手首/指に合わせて構図を変え、スマホや地域/カードで顔やジュエリーを切りすぎない。新規は元比率優先で表示し、寸法/形式/容量/alt/台帳/生成プロンプト/由来を記録。AI性のmetadataは使う形式と現行一次仕様を確認して保持する。
- R5 Google等の現行一次資料で英語タイトル/説明、英米のjewelry/jewellery等の自然な語、種類/素材/産地/作り手の検索意図、canonical/hreflang/内部リンク/sitemap/画像alt/構造化データを点検し改善する。検索語の羅列、重複する英米用ページ、未確認の検索量・順位・レビュー・Offerを作らない。
- R6 技術的にクロールしやすいことと、実際のインデックス/検索流入/順位を分ける。公開検索で結果が見つからないだけで未掲載と断定せず、Search Consoleの未接続/未確認は正直に残す。サイト追加・所有確認・sitemap送信を実行済みとしない。
- R7 価格/購入証跡/広告の二重承認・host・locale/公式とMaps/SORA/Contact非公開/ブログなし/日英切替を維持。型・単体・本番ビルド・画像全件/PCスマホ・メタ・リンク・広告切替・公開を実検証し、全ソース/画像/生成履歴/更新手順を引き継ぐ。

合理的仮定：既存50品を対象に欠けた23枚を補い、今回商品数やslug/ブランド/repoを増減しない。内蔵image_genを用い、外部画像の利用許諾を生成依頼で代替しない。新規契約/課金/ドメイン/DNS/広告やアフィリエイト申請は行わず、既存ホストの収益化適合は未解決のまま別記録に残す。
