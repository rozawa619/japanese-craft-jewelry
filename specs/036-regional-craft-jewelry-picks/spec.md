# 036 産地ごとの工芸ジュエリーを増やす

47都道府県の紹介を維持しながら、掲載点数の少ない産地に作品を追加する。読者は素材・仕立て・形を比較し、日英の詳細から、確認した販売先と選択肢へ進める。

| 要件 | 実装タスク | 確認 |
| --- | --- | --- |
| R1 産地の特色が伝わる | 仕立てや用途が既存品と異なるジュエリーを選ぶ。素材産地、作り手所在地、取扱店を一次情報で区別する | [照合記録](../../docs/research/regional-craft-picks-2026-11-24.md)と日英の産地・技法・商品ページ |
| R2 購入の根拠を確認できる | 注文受付、品番、選択肢、国内価格と確認日を台帳に追加する。店舗は公開情報で確かめ、選択品の店頭在庫は事前確認として扱う | [購入根拠](../../src/data/purchase-evidence.json)、[出典](../../docs/research/sources.json)、公開の商品詳細 |
| R3 見た目から選べる | 日英で商品ごとの紹介・比較・3問答を作り、着用と単体のAIイメージを用意する。実物画像への公式リンクとAI表示を添える | [着用イメージ記録](../../docs/image-generation-styling-v36.json)と[単体イメージ記録](../../docs/image-generation-solo-v36.json) |
| R4 既存の検索と公開を検証する | 既存の商品、県・工芸の導線、スマホ、通常リンク、広告判定を継承する。公開後に対象ページの照合結果を残す | [検証記録](validation.md) |

商品、作り手、素材、購入根拠、店舗、画像を既存の台帳とIDで連携させる。県ページは新商品との関連をカタログから取得する。都道府県ごとの紹介文は `src/content/places/` と日本語の `src/content/places/ja/` に置く。 [編集ガイド](../../docs/editing-guide.md)
