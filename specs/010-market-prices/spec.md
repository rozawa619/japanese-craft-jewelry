# 010 日本で買う参考価格と海外通販価格

2026-11-16 / Version0.10.0予定 / 作業中

最新ユーザー指摘: 日英切替で凛然星華がJPY26400からUSD288となり為替換算と合わない。訪日客は日本でより安く買うことを目当てにする。表示の通貨と言語、購入市場を混同しないよう見直す。009の地域セレクト/画像/公式URL/店舗案内を維持。

- R1: 日英とも日本国内の確認済み参考価格を主表示にする。既存localizedPrices.jaがある商品はその実額/日付を使い、価格正本を上書き・換算しない。JPYの国内掲載価格は保持。価格不明は不明のまま。未確認の実店舗価格を『現地確定価格』としない。
- R2: 海外向けの別ストア価格が確認できる商品は、国内価格と別市場の実額として表示。『海外通販参考価格』等で区別し、為替換算額と誤認させない。送料・税すべて込みや差額すべて送料と断定しない。
- R3: 国内参考価格には国内公式商品/カタログURLと店舗案内への入口を対応させる。海外通販価格は海外ストアCTAと対応させる。通常の公式リンクと将来の承認広告リンクは分離し、日英/merchant/programの既存ゲートを保つ。
- R4: home代表・地域行・商品カード・比較表・商品詳細・追従CTAの主価格/市場/確認日を整合。言語ボタンで購入市場が自動的に変わったように見せない。価格差が分かる簡潔な消費者向けの表示にする。
- R5: 仕様/原典/データ分離、型/テスト/build/日英スマホ/リンク対応/広告切替/公開/全ソースを更新。為替レート・店舗在庫・訪問時価格を捏造しない。

確認済み例: BECOS同SKU s0138-028は日本向け税込26400円、海外向けUSD288。BECOS Global公式shopping-guideに海外ストア価格は国際向け運営/英語サポート等の条件を反映する説明がある一方、商品ページは送料をcheckout計算、輸入税等は別行と案内。個別価格差の内訳は未公表。実店舗の当該SKU価格は未確認。
