# 035 全国の工芸アクセサリーとエリアから探す導線

日本を訪れる読者が、旅行先の地域から工芸アクセサリーを探し、日英の商品詳細と公式購入案内へ進めるようにする。GitHubの現行 `main` にあるSORAプロフィール、公開動画との連携、既存商品と購入表示を引き継ぐ。

| ID | 要件 | 確認条件 |
| --- | --- | --- |
| R1 | 全国47都道府県から探せる | 旧全国版の19候補のうち公式購入経路を再確認した商品を掲載し、既存の69商品と合わせて47都道府県・88商品とする |
| R2 | 現行の購入根拠を商品に付ける | 公式販売先、国内価格、該当品番・金具・選択肢、確認日、確認範囲を記録。製作地、素材産地、取扱店の所在地を区別する |
| R3 | 着用イメージから商品を確認できる | 新19商品に、21〜30歳の架空の日本人成人女性を描いた着用AI画像を用意。明るい表情と清潔感のある肌、装身具の見やすさを確認し、日英でAIイメージと実物の確認先を表示する |
| R4 | 旅行先の順序で絞り込める | 地域ブロック→都道府県→根拠のある県内エリア→商品。首都圏から東京・神奈川などを選べ、神奈川では箱根や鎌倉などから該当作品へ進める |
| R5 | 操作と既存公開導線を保つ | 日英・スマートフォン・キーボードで操作できる。日本地図と県への通常リンクを併用し、商品・SORAプロフィール・購入先の既存URLを確認する |
| R6 | 追跡・更新できる | 商品・出典・購入・場所・画像・エリアの構造を分け、一次照合と検証結果を仕様から追えるようにする |
| R7 | スマートフォンで旅先検索に入りやすい | 日英トップの最初の画面から旅先検索へ移動し、結果内の商品リンクを44 CSS px以上の高さでタップできる |

エリアは、旅行者が目的地を見つけるための分類。市区町村や工芸品との関連が確認できる範囲で設定する。全国の地域階層と、首都圏・神奈川での絞り込みは旅行サイトの情報設計を参考に、このサイトのデザインと商品情報を使って構成する。[楽天トラベル 首都圏](https://travel.rakuten.co.jp/metropolitan/) · [じゃらんパック 神奈川](https://www.jalan.net/dp/kanagawa/) · [日本政府観光局 神奈川](https://www.japan.travel/en/destinations/kanto/kanagawa/)

着用イメージは独自に生成し、実在の著名人の顔や第三者の掲載写真を参照素材に使わない。SORAの動画台帳で参照する既存の画像IDとパスを引き継ぐ。
