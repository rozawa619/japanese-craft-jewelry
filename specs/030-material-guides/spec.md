# 030 ガラスと木のジュエリーを素材から探す

ガラスを使った商品と木を使った商品を、日英の専用ページで比較できるようにする。商品一覧と既存フッターを入口に、素材の選び方、国内参考価格、商品詳細と販売先へ進める構成にする。

| 素材 | 対象ページ |
| --- | --- |
| ガラス | `/ja/materials/glass/` と `/en/materials/glass/` |
| 木 | `/ja/materials/wood/` と `/en/materials/wood/` |

- 掲載対象は[商品台帳](../../src/data/catalog.json)で `published` かつ対応する `materialIds` を持つ商品。掲載順は既存の商品一覧の編集順を使う。該当する公開商品がなくなった素材は、ページ・導線・サイトマップから外す。
- [素材ページの文面](../../src/lib/material-collections.ts)で、確認済みの技法と商品の具体例に基づく日英の選び方を管理する。カードの価格、着用画像、画像開示と販売先は既存の共通部品から表示する。
- 各素材ページを通常のHTMLリンクでたどれ、JavaScriptが無効でも該当する商品を表示する。選択中の素材で価格順や他条件を使う場合は、既存の商品一覧に進む。
- ページごとに日英の見出し・説明・canonical・相互hreflangを付け、公開サイトマップに追加する。
