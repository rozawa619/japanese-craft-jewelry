# 026 神奈川5商品の着用イメージ

2026-11-19。神奈川の特集と商品詳細で使う、陽雅堂3点とDahliacyan2点の着用イメージを差し替える。

## 受入条件

- 既存の商品写真に合わせ、淡い壁とやわらかい光の室内背景を使う。
- 架空の20代前半の成人モデルを用い、目視で確認できるほくろや濃い点状のシミを避ける。
- 正面、横、装身具を見るカットを組み合わせ、自然に笑う表情を含める。
- 着用アイテムが見える3:2の画像と日英のAIイメージ表記を用意する。
- 画像登録・生成記録・出力照合を揃え、差し替え前5枚を現行配信から外す。

対象は[神奈川の追加商品](../025-kanagawa-accessories/spec.md)の着用イメージ5点。
