# 009 旅先から選ぶ工芸ジュエリー

2026-11-16 / 予定 Version0.9.0 / 実装・検証中

最新依頼: 浜松屋18Kピアスの画像欠落理由を説明して補完。商品セレクトは左に産地、右に代表する掲載アクセサリーを1点置き、地域クリックで地域内の商品群へ。訪日旅行者が多い都道府県TOP10を多い順に掲載し、各地の代表的工芸を押さえる。画像はほくろ・シミのない方向、27–33歳程度の架空日本人女性でかわいい系と美人系を混ぜる。

## 要件と受入条件

- R1: 18K商品に正常に読込めるAI着用イメージを登録。価格・在庫・18K表記の確認範囲を画像から補完しない。既存画像も目視し、ほくろ・シミの方向を修正。
- R2: home・商品セレクト・産地一覧は同じ地域選択部品を使い、デスクトップは地域左/代表商品右。モバイルも地域名と対応商品が一組として分かる。地域名をクリックするとその地域の掲載商品一覧へ進む。代表商品自体の詳細リンクも別に置く。
- R3: 観光庁インバウンド消費動向調査2025年暦年確報・表6-1の全目的/全国籍・地域の都道府県訪問率でTOP10を順序固定。Tokyo/Osaka/Chiba/Kyoto/Fukuoka/Kanagawa/Nara/Yamanashi/Hokkaido/Aichi。年・指標・一次出典を明示。訪問率を人数・宿泊数・商品売上人気と呼ばない。
- R4: 新規6道府県は公式商品・産地を確認したジュエリーを原則2点ずつ追加。空ページを作らない。有名どころは工芸としての代表性を一次情報で確認し、未確認の売上No.1/認定/人気を主張しない。従来の佐賀・石川も選べる。
- R5: 全新商品に日英本文・独自選定理由・公式商品URL・公式ホーム・店舗案内または正確な通販代替・出典/確認日を揃える。価格・広告・事実の正本分離、通常リンクfallbackと未申請状態を維持。
- R6: 日英同ページ切替、スマホ、キーボード、地域遷移、フィルター、全画像、公式リンク/地図、広告切替、CSP、buildと配信を実検証。SDD・更新手順・全ソースを更新。

仮定: 「両公社」は旅行者の誤入力と解釈。比較可能な最新の通年確報を使用し、未完の2026年四半期とは混ぜない。代表商品は当サイトの編集上の選択であり、都道府県公認や売上順位ではない。ブログ/Contact追加なし、SORA、短いAIイメージ表記を維持。
