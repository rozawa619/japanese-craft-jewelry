# 005 魅力から選べる商品紹介

2026-11-16。ユーザーは『確認できた仕様』が先に並び、『ピアスの穴がある人』という自明なおすすめが購買動機にならないと指摘。アフィリエイト紹介としてデザイン・装い・欲しくなる理由を主役に作り直す。ブログへは戻さない。

| ID | 受入条件 |
|---|---|
| PA-001 | 商品の第一画面は魅力の見出し/短い紹介/画像/価格/見つけやすい外部CTA。確認表・調査報告・自明な使用条件を推薦理由として先に出さない。 |
| PA-002 | 全8商品のカード/冒頭/本文を日英で見直す。デザインや装いに根拠のある違いを表現し、C/D等の品番の違いだけで選ばせない。 |
| PA-003 | 参考3媒体/商品ページを実見し、観察した情報順序から独自設計。コピー/画像/レビューを移さず、売上改善を実証したと主張しない。 |
| PA-004 | 商品事実はcatalog、表示コピーは安定productIdのproduct-stories、商品本文はproducts、画像はregistryに分ける。価格/広告URLをストーリーへ複製しない。 |
| PA-005 | 仕様/配送/購入前確認/工芸出典は下部の初期closed detailsへ整理。価格確認日/外部購入先/AI非実物/実際の広告関係は適切に見える位置へ。重要な注意を捏造・消去しない。 |
| PA-006 | スマホで主CTAを見つけやすくする。追従CTAは主CTAを通過してから表示し、footer付近では隠す。共通広告resolverと表示を維持する。 |
| PA-007 | 日英・SORA・全国・旧URL移行・noBlog・CSPを維持。型/リンク/広告5ケース/PC390320/折りたたみ/追従CTA/公開HTTPを実測し文書/全ソース更新。 |

事実の限界：浜松屋のcatch型の実物形状は18K欄の写真から確定できない。AI着用図をその商品の忠実な再現とは主張しない。未知の寸法/重量/低アレルギー/装着感、使用体験、レビュー、限定在庫、値引き、売上は作らない。今回のデザイン/コピー改善と売上向上の実績は別。
