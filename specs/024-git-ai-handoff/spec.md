# 024 Gitだけから継続できるAI引継ぎ

2026-11-17。ユーザー依頼は「引継ぎ資料を全部Gitに上げ、そこを読ませれば続けて作業できるようにする」。サイトの機能・商品・画像の再制作は対象外。

- R1 `START_HERE.md`を唯一の短い入口にし、README/AGENTS/コピー用promptから誘導する。
- R2 公開0.18.0/完了023と今回の資料整備024、公開appと文書HEADを区別する。未実施の新規制作を勝手に始めない。
- R3 正本・起動・env・依存・検査・公開/復旧・外部条件を、作成者PCなしで追える。
- R4 画像原本/現行納品ZIP/外部proofをGitHubに保存し、URLとSHAで取得・照合できる。秘密情報や認証値を保存しない。
- R5 raw PNG/退役画像はサイトへ配信せず、原本はGitHubの配布assetとする。通常buildには不要。
- R6 fresh clone相当のソースから依存導入・型/単体/build・画像/文書検証を実行し、全公開出力が直前の公開版と同一であることを確認する。
- R7 実測、失敗と修正、未実施範囲を検証記録へ残し、GitHubのmainで資料と取得先を確認する。

契約/CMP/実アカウント/連絡先やChrome/NodeのOS導入はユーザー環境の条件で、資料追加で完了扱いにしない。過去の1198ファイルはmodels-023納品snapshotの実績で、現在のGitファイル数の固定条件ではない。
