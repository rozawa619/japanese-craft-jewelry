# 015 商品単体の画像・リンク名・小型地図

2026-11-17、014実装中の追加依頼。014のPrivacy/内容充実も継続し、同じ0.14公開版へ含める。

- 生のURL文字列を、行き先が分かる商品/ブランド/店舗リンク名へ置き換える。href、外部表示、言語、市場、広告承認gateを保持。
- 全公開商品の『惹かれる、その理由。』にジュエリー単体のAIディテール画像を添える。既存AI図と公式情報を参照し、新規の写真転載はしない。短いAI captionと実物確認の公式リンクを表示、正確な製品写真・販売数量・裏面/金具の証拠とは扱わない。生成原本・prompt・権利/参照記録を保存。
- 確認済み店舗へ小型のGoogle埋込み地図を用意。Google公式の埋込み機能を使い、地図/ロゴ/帰属表示を隠さず、スクリーンショットの転載やGoogle風の自作地図は使わない。
- 地図は送信先と情報送信を示して同じページで表示を選択した後に読み込む。地図の選択と広告の認定CMPを混同せず、自前Cookie/localStorageを追加しない。外部GoogleMaps/経路リンクも保持。
- 店名検索で違う支店や一時休業が出る場合は公式住所・営業根拠を再調査し、Google表示だけで営業停止を認定しない。未解消は公式案内fallbackへ。
- iframeのURLを固定origin/許可パスに制限し、CSPは必要なGoogle frame originだけ追加。Privacyの地図利用・無広告検査・ブラウザ実測を新しい実態へ合わせる。
- JA/EN、PC/スマホ、生成物、地図読込前後の通信/レイアウト/出典、全source/納品を実検証。新規課金・APIキー・契約・広告配信は開始しない。
