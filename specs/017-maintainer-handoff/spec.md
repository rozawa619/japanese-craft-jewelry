# 017 AIと人のための保守・引継ぎ

2026-11-17。依頼は別のAIが会話履歴なしで再開できることと、人がsource/READMEから修正できること。サイトの見た目/商品/価格/広告/公開先を変更する依頼とは区別する。アプリversion0.15.0を保持し、文書改訂017として扱う。

- R1 READMEを開始点にし、現在の状態・正本・起動・編集・検証・公開・納品・未完了条件へ迷わず到達できる。
- R2 AI用に単独で渡せる引継ぎと実行promptを置く。最新/履歴、実測/未実施、アプリcommit/文書commit/ZIP版を区別し、古い仕様の固定件数を現行制約へ転用しない。
- R3 人向けに実データの部分例、変更目的→対象ファイルの対応、日英と市場の違い、新商品draftから公開まで、画像/出典/店舗/順序の更新方法を示す。
- R4 構造/データflow/ブラウザー処理/守るgateを文書化し、必要なsourceコメントを補う。挙動変更やデータ分割の大改修はしない。
- R5 fresh clone/ZIPだけで実行できる手順にする。build必須docs JSON、Chrome、env/base/port、Node最低版、署名/原本/アカウント等の未同梱物を明記。私的artifactsだけにある主要検査・ZIP検証を再実行可能なscriptsへ昇格する。
- R6 文書リンク/命令と実装の整合、追加tool、通常verifyを実測。アプリ生成物が既存公開版と同一であることを確認し、全sourceとZIPのSHAを再照合する。公開側を変更しない文書/tool改訂はGitへ保存し、公開Actionsを新たに成功したと捏造しない。

原則: SORA/全国/JAEN/50商品と98AI画像/Contact・ブログ・決済なし/通常広告gate/off固定/CSP/Source開閉を保持。新課金・アカウント・申請・DNS変更は不要。AIの完全無誤謬は保証できないため、検証可能な正本と復旧手順で引継ぐ。
