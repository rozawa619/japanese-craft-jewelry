# 008 公式情報と店舗への案内

2026-11-16 / Version0.8.0

最新ユーザー指示: モデルは20代後半〜30代前半。全商品に公式サイトURLを紹介し、現地購入場所の店舗紹介とGoogleMapを追加。法的問題を確認し、問題がある形態は行き方・買い方の案内へ置換する。007の素材拡張/日英/通常リンク/短いAI注記を維持する。

- R1 年齢方向は概ね27–33歳。より上に見える2画像をlate twentiesへ調整し、生成履歴と現行registryを更新。
- R2 公開16商品すべてで言語に合う公式商品/公式カタログのURLを通常リンクとして見える形で提示。確認できたメーカー公式URLも別に案内。未特定メーカーを捏造しない。
- R3 公式実読済の店舗・住所・営業時間・公式アクセスとGoogleMap外部検索/経路リンクを追加。ブランド取扱と個別SKU在庫を区別する。未確認の常設店や登記住所を店舗にしない。
- R4 実店舗が公式確認できない商品は、公式オンライン/現行stockists案内で買い方へ進む。未確認場所にMAPを付けて穴埋めしない。
- R5 店名/住所等の確認済事実を独自文で紹介し、写真/ロゴ/地図/口コミの転載や地図埋込はしない。Google公式Maps URLsの正規リンクで行き方を案内。一次資料の法務確認・判断と限界をdocsへ記録。『すべて合法』を保証しない。
- R6 店舗データ/商品関係/紹介文/URL生成/部品を分離。出典・日付・全product対応・日英・MAPエンコード/安全URL・CSP・build・スマホ・公開を検証し全ソースを残す。

仮定: GoogleMapは埋込でなく外部リンクを採用し、ユーザーが開くまでGoogleへの送信なし。実店舗の裏付けがなければ公式通販案内へ。店頭在庫/営業日の変動は公式確認へ簡潔に案内。自サイトContactは非公開のまま、相手店舗の公式アクセス/公式問合せへのリンクはその店の情報として扱う。
