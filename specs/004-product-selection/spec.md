# 004 商品セレクトを中心にする

2026-11-16。ユーザーの最新依頼：読みもの/ブログは不要。おすすめ商品を増やす、セレクトショップの役割を持つ紹介サイトにする。従来のメディア中心の要件より今回の指示を優先する。販売/決済/発送は従来どおり外部販売店。

| ID | 受入条件 |
|---|---|
| PS-001 | トップにおすすめ商品、種類別の選び方、商品への直接導線。ブログ/読みものの一覧・ナビ・記事カード・読むCTAを設けない。全国対象を維持。 |
| PS-002 | 2つの耳飾りの紹介本文とAI着用図を対応する商品詳細に統合。商品名・価格・選ぶ理由・確認点・販売店CTAで構成し、著者/読了時間/記事の見せ方を外す。AI/非実物表示と商品事実は分離維持。 |
| PS-003 | 種類/産地/技法/工房を商品分類の入口として扱い、分類ページは商品一覧を先に出す。背景は補足に留める。未確認地/空県ページを作らない。 |
| PS-004 | 旧journal公開本文はdraft履歴として保持。過去の14URLは固定の適切な商品/一覧/技法へHTML移動ページ（noindex、canonical/Articleなし）として誘導。ナビ/正規sitemap/公開本文リンクには残さない。HTTP301とは報告しない。 |
| PS-005 | SORA、Japanese Craft Jewelry、日英の右上1ボタン、既存商品slug、出典/確認日、広告二重承認/host制限/開示、CSP等の安全性を維持。 |
| PS-006 | 型/参照/ビルド/内部リンク、PC/390/320、商品画像とAI表示、日英/フィルター、旧URL移行、通常/広告fallback、public/preview、公開URLを実検証し、文書と全ソースを更新。 |

仮定：おすすめは実物の比較試験・順位付けではなく、資料に基づく選定。トップの順序はselection設定の安定ID、価格/URL/事実はcatalog。解析/課金/カートを追加しない。地域/技法の説明は商品選びの補足として折りたたみ表示する。
