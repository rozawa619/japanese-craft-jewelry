# 023 人物着用イメージを日本人女性の生成設定へ統一する

2026-11-17。対象アプリ0.18.0。開始基準は公開0.17.3/app ef8ae160e7fc7d2b41cdce1063094313b719df6e、文書HEAD240e1fed21a3ffe50b3f1ea2cfa84b285d497f2c。最新依頼は「日本人オンリー」「20代半ばも良い」「びっくりするぐらいかわいいやキレイな人」を含む画像の差し替え。以前の日本/米国/英国混在・27〜33歳目安を、この生成方針へ更新する。

## 要件

- R1 全公開商品の人物着用画像を監査し、既存の生成prompt/構造化設定を根拠に、架空の日本人女性と明記された画像だけを採用する。見た目から実在人物の国籍・民族・年齢を推定/認定しない。不明な履歴へ後付けで「日本人」と記入しない。
- R2 監査結果は必須置換22画像・既存保持36画像・記録不明0。監査数と生成/採用/公開の状態を区別する。ローカルでは新22画像の生成・目視採用・参照切替を完了し、60公開商品に対する58人物画像の参照関係を維持した。共有画像に複数productIdがある場合は全参照を確認する。画像数は今後の固定上限ではない。
- R3 新規人物は架空の成人日本人女性25〜33歳の生成設定とし、25歳を含む20代半ばも入れる。華やかなかわいさと洗練された美人系、髪型・表情・服装の変化を組み合わせ、それぞれの商品に合う構図へ。実在人物/著名人の模倣、未成年に見える描写を避け、従来のほくろ/シミを目立たせない方向性を継承する。
- R4 対象アクセサリーの形・色・着ける位置を調査済みの文章や許可された自作参照から引き継ぐ。公式写真の無断転載/hotlink/生成入力化をせず、AI画像を実物写真・正確なSKU再現・実際の試着/着用レビュー・個数/素材/寸法の証明として扱わない。
- R5 built-in image_genで生成/編集し、結果を目視して採用/棄却・理由・prompt・日時・元PNG・寸法・SHA・変換方法を記録。生成はCLI/APIへ無断切替せず、意味を変える画像編集を変換ツールへ代行させない。新logは`docs/image-generation-japanese-v23.json`とし、旧生成記録を上書きしない。
- R6 新ファイルは`public/images/styling-jp-<productId>-v23.webp`、元PNGは納品先の`generated-originals/0.18.0/styling-jp-<productId>-v23.png`。旧人物画像のbytesを上書きせず、差し替えた22画像をretiredとして配信/全source ZIPから外し、旧記録/原本を保持する。今回の明示許可は対象人物画像だけであり、単体60画像と保持36人物画像はbytes不変。
- R7 `editorial-images.json`、asset台帳、生成manifest、日英alt/AIcaptionを一致させ、全公開商品の人物画像欠落をなくす。altはAIであることと見える装い/アクセサリーを説明し、画像から実在人物の国籍や年齢を認定しない。台帳のactive/retiredと実配信/ZIPの集合を照合する。
- R8 既存の3:2自然比率/contain、顔・耳・ジュエリーの非crop、Heroの上下余白なし、Top10/DISCOVERの共通サイズ、日英・スマホ・24県の画像/価格/リンク切替を保つ。新画像が実際の枠で見やすく、AIcaptionが常時表示されるか確認する。
- R9 商品/価格/出典/公式URL/店舗・全国60公開/24県の構造、SORA、広告off/実提携未申請・Google店舗Mapsの同意/30日保存を変更しない。旧「全人物bytes不変」の例外は監査で確定した置換画像だけに限定し、保持画像/単体/商品正本の保全を別に検査する。
- R10 仕様/設計/タスクと画像監査/生成/採用/検証/公開/ZIPの段階を対応付ける。新画像の実表示・リンク・build・日英/スマホ・公開app/Actions・全source/原本の集合とSHAを確認し、未生成/未採用/未公開を成功扱いにしない。

## 範囲外と継承

商品追加・商品単体画像の作り直し・レイアウト再設計・広告申請/実ID接続・ホスト移転は行わない。本人情報/契約/法務/権利・商用ホスト・認定CMP等の残条件を、画像更新の成功で完了扱いにしない。

## 実装状態

新規22画像はbuilt-in image_genで生成し、22枚すべてを旧自作AI参照と個別に目視して採用した。新規の設定は25〜30歳（25歳6枚）で、許容する25〜33歳の範囲内。かわいい系11枚/綺麗な系統11枚とし、既存のJapanese設定36画像を保持する。元PNG/参照原本・prompt・採否・SHAを新manifestと別納品領域へ保存した。ローカルの画像設定/保全/build等の結果は[validation](validation.md)を参照する。公開app/Actions・実URL・全source ZIPの確認は別段階で、未確認の完了を意味しない。
