# 商品セレクトの構成（0.4）

2026-11-16。Japanese Craft Jewelryは、おすすめの商品を探し、仕様と選ぶ理由を見て、販売店へ進む体験を主役にする。ブログ/読みもの一覧、読了時間、著者・記事更新日を前面に出すレイアウトを外す。実装と公開確認の最終状態はdeployment-results.jsonを優先する。

トップは短いセレクトの案内と商品への入口、おすすめ商品、ピアス/イヤリング/ネックレスの種別入口、産地を使った商品選びの順に構成する。代表商品とおすすめ順序はsrc/config/selection.tsで商品IDにより管理し、欠品をおすすめ候補へ混ぜない。商品一覧は公開カタログの絞り込み、商品詳細は商品名・価格・販売店・選定理由を中心に置く。販売店へのボタンは外部で購入することが分かる表示にする。

2商品のカードと詳細は独自AI着用画像を使い、画像に隣接した常時captionでAI/非実物と示す。画像のない商品は自作の抽象装飾を使い、別商品の写真で埋めない。素材や金具の不明点、価格の確認日、販売/発送の担当、一次出典を必要な場所で確認できるようにする。偽の試着・レビュー・推薦実績は加えない。

産地と技法は読みものではなく商品分類の一覧。背景情報は折りたたみに収め、空ページを公開しない。全国展開時も共通データとテンプレートから増やす。旧journalはnoindexの固定移行口のみを残し、通常ナビ・商品導線・サイトマップへ出さない。

名称はJapanese Craft Jewelry、運営者表示はSORA。PC/スマホの右上に単一の日本語/English切替を保ち、同じ商品・絞り込みへ戻れるようにする。色・余白はtokens.cssを共通利用し、外部Webフォントや解析を追加しない。

参照媒体の文章・写真・ロゴ・コード・特徴的な組み合わせを複製しない。学んだ一般機能は分類の揃った商品情報、選定理由、販売店導線、確認日、広告開示。売上・流入改善の因果効果は未検証。0.1〜0.3の構成は過去spec/レポートとGit履歴へ残し、現行の設計と混同しない。
