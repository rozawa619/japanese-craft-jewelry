# 商品の魅力と購入導線（0.5）

2026-11-16。Japanese Craft Jewelryは、選んだ商品を自分の装いに取り入れたくなる紹介を目指す。上部はデザインの魅力と服との関係、価格、販売先への導線に使う。仕様や確認事項は下部の閉じた補助情報にまとめ、興味を持って検討するときに開ける。ブログや読みもの一覧へ戻さない。

## 商品詳細の順序

1. 技法/種類、商品名、短い魅力の見出し。
2. 画像と、日常の服にどう合わせるかを伝える導入。
3. 価格と確認日、主CTA前のcompact広告開示、遷移先に合った販売店CTA。
4. 3つのデザイン/スタイルのポイント、選定理由、具体的な服の組み合わせ。
5. 販売店への再導線。
6. 閉じたdetailsで仕様・配送/返品・作り手/産地・出典を確認。
7. 関連商品。

訴求文はsrc/data/product-stories.json、読込はsrc/lib/product-stories.ts。全8商品のen/jaにheadline、standfirst、highlights3件、outfit.title/bodyが必要。価格・技術仕様の数値・広告URL/承認状態はcatalogに残す。商品本文は商品の魅力を具体化し、種別の前提や資料未掲載の長い羅列を冒頭の推薦理由に使わない。

丸山C/Dは公式画像で視認した星状の輪郭と縦長バー/矢羽根状の模様を紹介に使う。出典と確認範囲はdocs/research/product-merchandising.md。参照サイトの一般的な情報順序から設計し直し、文章・写真・レビュー・ブランド・画面の組み合わせを複製しない。

## 購入と広告の境界

CTAは公式カタログ/商品ページの実際の役割に合う文言にする。当サイト内で購入できると見せない。主CTA前のcompact Disclosureは常時のページ構成に残し、広告承認状態と表示/relを一致させる。

スマホ追従CTAは主CTAを通過した後だけ表示し、フッターが見えると隠す。初期表示で内容を覆わず、追従だけ別のリンクや承認状態を持たせない。全CTAは共通RetailerLink/resolverで通常・広告・非表示を決める。

## 画像と商品カード

AI着用図は実在商品の写真や正確な再現として扱わない。短いcaptionでも、AIであり実物写真/再現ではないことを画像の近くに常時表示する。未許諾の公式写真は掲載せず、画像がなければ明示した抽象装飾を使う。

商品カードはデザインの魅力を伝える短い紹介と価格・販売先を示す。作り手不明の商品は実在販売店を「取り扱い」として表示し、メーカーに仕立てない。製造地や金具などの不明情報はデータと商品詳細に保持する。

## 全体の一貫性

トップのおすすめ順序はselection.ts、商品一覧は公開カタログの分類と絞込。地域/技法は商品一覧を先にし、背景をdetailsへ。全国対象、SORA、日英の右上単一切替、安定商品slug、空分類を出さない仕組みを維持する。外部Webフォント/解析/新規adscriptは加えない。
