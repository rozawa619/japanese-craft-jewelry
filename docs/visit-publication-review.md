# 店舗紹介とGoogleマップ案内の確認

確認日:2026-11-16。今回採用する掲載方法の確認であり、個別の法的意見・世界中の法域を含む適法保証ではない。結論を公開UIへ長く載せず、ここへ根拠と判断を残す。

## 採用する方法

公式に公開された来店先の店名・住所・営業案内を確認し、自分たちの短い文章で紹介する。公式の商品URL、店舗公式情報、Google Mapsの場所/経路リンクへ案内する。Googleや店舗の地図画像・外観写真・ロゴ・口コミ・紹介文章をコピーしない。地図の埋込やスクリプトは追加せず、既存CSPを維持する。

文化庁は単なる事実・データと創作的表現を区別している。このため確認済みの基本情報の独自要約を採用し、ページの文章や写真全体の利用許諾とは扱わない。他の権利や利用条件の確認が不要になるわけでもない。[文化庁の説明](https://www.bunka.go.jp/seisaku/chosakuken/seidokaisetsu/chosakukensha_fumei/)

Googleはウェブサイトから検索・経路を開くMaps URLsの書式を公開している。api=1と正しくエンコードした店舗名/住所を使い、originは収集しない。APIキーや地図画像の転載は使わない。[Google Maps URLs](https://developers.google.com/maps/documentation/urls/get-started)

地図画像には利用・表示条件があるため、今回の画面は地図サービスへ開くリンクにする。これは埋込がすべて違法という判断ではない。[Google Geo Guidelines](https://about.google/brand-resource-center/products-and-services/geo-guidelines/)

紹介先の名前は訪問先の識別用のテキストとし、公式提携・認定や店頭在庫を示すバッジにしない。将来広告を使う場合は周囲を含め広告だと分かる表示を維持する。[消費者庁Q&A Q13](https://www.caa.go.jp/policies/policy/representation/fair_labeling/faq/stealth_marketing/)

## 訪問情報の限界と代替

作家の住所や登記住所だけでは店舗にしない。過去の催事を現行常設店にしない。ブランド取扱いと個別SKU在庫を区別し、必要な事前連絡や公式で確認できたアクセスを示す。現在の実店舗が確認できない場合は、架空のMAPを作らず、公式オンライン商品ページでの買い方へ案内する。相手の紹介資料を読み直すだけで、メール・申請・問合せ・注文は送らない。

この条件での事実紹介と正規外部リンクによる行き方・買い方の案内を採用する。個別のサイト契約や紛争、他国法まで問題がないとの保証ではない。確認できない項目は掲載を控える。本文を取得できなかったe-Govと403の特許庁ページを実読済みの根拠にしない。正確な実読記録はresearch/visit-publication-legal-v8.json。
