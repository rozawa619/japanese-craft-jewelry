## 判断の一次資料

Googleは言語ごとの別URL、言語切替のリンク、各ページが適切な言語で書かれていることを勧めている。利用者の言語を推測して別言語へ強制転送すると、利用者や検索エンジンが全版へ到達できなくなるおそれがある。このためブラウザ言語は入口の表示順にだけ使い、/ja/と/en/を自動転送しない。[Google Search Central: 多地域・多言語サイト](https://developers.google.com/search/docs/specialty/international/managing-multi-regional-sites)

hreflangは自身を含む各言語を完全URLで相互に示す。x-defaultは未対応言語向けのfallback。今回のx-defaultは各商品の英語版であり、全商品をトップへ集めない。[Google Search Central: 言語別ページの指定](https://developers.google.com/search/docs/specialty/international/localized-versions)

サイトマップと辿れる内部リンクは発見の助けになるが、クロール・インデックスの保証ではない。公開済みの中身のあるページだけをsitemapへ載せ、Contact・旧journal移行口・下書きを除外する。[Google Search Central: サイトマップ](https://developers.google.com/search/docs/crawling-indexing/sitemaps/overview)
