## SORAが申請前に確認すること

1. [BECOS公式募集](https://en.thebecos.com/pages/become-a-becos-affiliate)から[現行申込窓口](https://becos-en.goaffpro.com/)を開き、表示された規約と入力項目を確認する。本環境ではそのJS画面を読み取れず、必要な個人情報や同意項目は確定していない。
2. 日本居住者がこの日英サイトで参加できるか、紹介する個別商品が対象か、商品別リンクを生成できるかを確認する。BECOSで販売中という事実と広告対象の確定は別。
3. 報酬率、成果確定・取消、計測期間、支払条件、禁止集客、固有の広告開示を確認する。これらは制作側の確認推奨で、公開募集本文が全項目を審査必須としたという意味ではない。
4. 写真を将来使う場合は権利と使用範囲を取得する。現在のAIイメージを含む紹介方法に別の制限がないかも確認する。
5. 規約や審査で公開連絡窓口を求められた場合は、実在する窓口を用意するか、そのプログラムの採用を見送る。現在確認できた募集本文だけからContactが全プログラム共通の必須条件とはいえない。
6. 実際のフォームで求められた真実の情報だけを入力し、規約に同意できることを確認して申請する。公開名SORAと契約上必要な本人情報は区別する。個人・支払・認証情報はGitHubへ保存しない。

2026-11-16現在、登録・照会・申請の送信は行っていない。BECOSの公開募集で確認できたのは無料参加・最大10%・サイト等向けの募集。最低商品数・最低記事数・最低アクセス数、公開Contact必須、日本居住者の可否、全商品10%は確認できていない。

## 0.10の購入市場と言語別リンク

BECOS9商品の国内JPY価格と海外ストア価格を別々の実額として保持し、日英とも国内参考価格を主表示する。海外価格は詳細の別枠。ENから日本向け、JAから海外向けの参照は通常公式URLのみ。日本語商品リンクはprogramId:nullで、英語提携の承認を移さない。広告化する際は承認された市場・ストア・言語・個別商品を確認する。現時点では両言語とも通常リンクで申請送信なし。国内購入先を使う訪日客の流れがBECOS Globalの成果対象になると推定しない。
