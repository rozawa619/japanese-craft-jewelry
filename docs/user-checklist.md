# 運営者が最後に決めること

1. ITOの仮称と運営責任の公開表示を確定。公開用メールを使う場合は実受信する値を設定（現在はGitHub Issuesで訂正受付）。
2. 検索公開するURLを確定し、PUBLIC_OPERATOR_NAME等を入力、readiness通過後にPUBLIC_PUBLISH_MODE=publicへ。現在のオンラインプレビューはnoindex。
3. BECOSの日本居住可否・報酬計測/支払・深いリンク・画像利用・禁止事項を公式窓口で確認して申請。現在の8商品は対象と確認できていないため通常リンクを維持。BECOS等の商品は別途一次調査して追加。
4. 商品写真を使う場合だけ対象商品の許諾を取得し台帳更新。現状は未許諾写真を使っていない。
