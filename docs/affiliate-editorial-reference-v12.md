## 今回の編集と画面の対応

- 商品一覧：個別の紹介文で、かたち・素材・モチーフのどこを見て選んだかを伝える。「選んだ理由を見る」から商品詳細へ進む。
- 商品冒頭：固有の見出しと説明、確認済み価格・公式購入先を維持する。その直後に「この一品を選ぶなら」を置き、「こんな好みに」「迷ったら、ここを比べて」の2つで選択を助ける。
- 選定方法：SORAが公式情報から選んだ提案であることを短く添え、既存の選定方針へつなぐ。実物の使用感・試着レビューと誤認させない。
- 商品比較：仕様表だけで終わらせず、各候補の固有見出しと選ぶ理由を先に置く。比較先は現に公開している商品に限り、種類・素材・寸法・価格は共通の正本から読む。
- 詳細情報：素材の未確認点や出典は既存の開閉欄で確認できる。未確認の重さ・金具・在庫・製造地を魅力として補わない。

実装は `SelectionDecision.astro`、`ChoiceDetails.astro`、`ProductCard.astro`、商品詳細ページ。表示文は `product-stories.json` の `decision.bestFor` / `decision.consider` と既存の独自紹介文・選択メモから読み、UIへ同じ商品説明を複製しない。カード・価格・公式URL・広告の正本と承認条件は変更しない。

新規候補の採否はこの媒体比較とは別に、メーカー/正規店の一次情報と現行の購入経路で判断する。未承認のまま通常公式URLで紹介できる構造、SORA、日英切替、短いAI表示、Contact非公開、ブログなしを維持する。
